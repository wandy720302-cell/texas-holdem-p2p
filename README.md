# 德州撲克 P2P

純前端、無後端、無帳號的德州撲克。最多 8 人同房間，透過 [PeerJS](https://peerjs.com/) 做瀏覽器對瀏覽器的 P2P 連線（架構沿用自 battleship 專案的 `net.js`）。

- 開房間的人是「房主」，房主的瀏覽器同時是遊戲邏輯的權威端（發牌、算牌、算勝負都由房主算）
- 其他人透過房間代號連進來，只送出「我要做什麼動作」，畫面完全依賴房主廣播回來的狀態
- 所有資料只存在記憶體裡，重整頁面或大家都關掉分頁，這局就結束、資料也不會留下

## 本機測試

ES module 需要用 http(s) 而不是 `file://` 打開，隨便起一個靜態伺服器即可：

```bash
npx serve .
# 或
python -m http.server 8000
```

打開兩個分頁（或用手機 + 電腦），一邊「建立新房間」一邊拿房間代號「加入房間」即可測試。

## 部署到 GitHub Pages

直接把這個資料夾推上 GitHub，開啟 repo 設定裡的 Pages，指到根目錄即可，不需要任何建置步驟。

## 目前規則 / 限制（MVP）

- 標準德州撲克規則：2 張底牌、Flop/Turn/River、check/call/bet/raise/fold，支援多人 all-in 的邊池計算
- 每人初始籌碼 10,000，小盲 50、大盲 100
- 特殊貨幣「希銘的子母車」：籌碼首次超過 10,001 時獲得 5 個，每個價值 168（純紀念戰績用，不能拿來下注）
- 房主離線 = 整場遊戲中斷（P2P 架構的天生限制，之後可以做房主轉移再解決）
- 沒有帳號系統、沒有跨局籌碼紀錄——比的就是當下這場誰籌碼多
- 沒有斷線重連保護、沒有行動時間限制，這些是已知的下一步優化項目
